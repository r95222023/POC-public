# PhotoGroup-132：純照片表面細化比較

實測日期：2026-11-10。沿用前次 34 張照片產生的相機姿態、去畸變影像、密集點雲與網格，未加入控制點、GPS／RTK、已知尺寸或外部相機校正資料。原始成果保持不變，相關輸入檔案 SHA-256 在執行前後一致。

## 方法

OpenMVS 2.4.0 CPU `RefineMesh`，2 個執行緒、降一級影像解析度、單一尺度、4 個鄰近視角，不細分面積、不補洞、不重建相機或深度圖。細化後沿用既有貼圖設定，停用接縫亮度調整與銳化，重新產生並內嵌 4096 貼圖。

此實驗主要調整頂點位置，並非藉增加面數改變呈現。原始點雲保留，另將可疑點投影到新表面，供預覽切換。

## 結果

| 指標 | 細化前 | 細化後 |
|---|---:|---:|
| 幾何頂點 | 50,035 | 50,035 |
| 三角面 | 99,953 | 99,953 |
| 邊界邊 | 125 | 125 |
| 非流形邊 | 0 | 0 |
| 退化面 | 0 | 0 |
| 原始稀疏點到表面距離中位數 | 0.0460626 | 0.0458036 |
| 原始稀疏點到表面距離 P90 | 2.870697 | 2.873927 |
| 中位距離占原始模型對角線 | 0.199905% | 0.198781% |

兩版均使用固定亂數種子抽樣的相同 512 個原始可靠稀疏點，未使用已貼回表面的點。中位距離下降約 0.56%，P90 略升約 0.11%，未呈現全面一致的改善。距離單位為未校正的重建座標，包含場景裁切、邊界與缺漏的影響，不是公尺誤差。

RefineMesh 內部最佳化目標由 83.92722 降至 73.52406（約 12.4%），45 次調整、引擎階段約 12 分 20 秒。這個目標包含其影像與正則化項，不能直接視為模型真實精度。僅此單次資料不足以宣稱優於原始版本或 iTwin。

## 重現

從 `image-stitcher` 執行，指定新目錄：

```powershell
.\.venv\Scripts\python.exe reconstruct_surface.py outputs\photogroup132\sift-cpu-1600 --output outputs\photogroup132\sift-cpu-1600\surface-refined --reuse-surface outputs\photogroup132\sift-cpu-1600\surface --refine
```

啟動對 `outputs/photogroup132/sift-cpu-1600` 的本機 HTTP 服務後，開啟 `/surface-refined/comparison.html`。參數與續跑方式見主 README。
